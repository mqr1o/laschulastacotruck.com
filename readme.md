# Las Chulas Taco Truck

Website for an authentic Mexican street-food truck on Mission Blvd in Hayward, CA.

**Live site:** https://laschulastacotruck.com

![Las Chulas homepage](screenshot.png)

## Features

- Bilingual: visitors choose English or Español on arrival and can switch at any time
- Menu, catering, reviews, about and location sections
- Catering booking call-to-action
- Embedded Google Map and tap-to-call phone number
- Responsive layout for phones and desktops

## Tech

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step), hosted on Netlify with continuous deployment from this repository.
